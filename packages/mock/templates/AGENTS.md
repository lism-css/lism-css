# AGENTS.md

This directory is a `@lism-css/mock` data directory.

1. Read [README.md](./README.md) first — it is the data contract for every file
   you may add or edit here.
2. Use the `lism-css-guide` skill for how to write the markup itself
   (primitives, tokens, Property Class). It is required, not optional.
3. Mirror the existing pages in `pages/` instead of inventing a new structure.
4. Verify your work with `npx @lism-css/mock check .` before reporting it as done.
   Start `npx @lism-css/mock dev .` only in the background, or let the user run it.

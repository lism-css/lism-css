## lism-css v.0.26.0 (2026.08.16)

### `lism-block` レイヤーの追加 (#546, #559)

- ベーススタイルをCSS側で管理する基礎部品（`b--`）用に `lism-block` レイヤーを追加しました。コアでは空のレイヤーで、`@lism-css/ui` やユーザー定義のクラスがここに配置されます。
- レイヤー順は `lism-base → lism-block → lism-trait → lism-primitive → lism-custom → lism-utility` です。`lism-block` を `lism-base` の直後（弱い位置）に置くことで、`b--` のベーススタイルに対して、明示的に付与したクラス（`is--` / `has--` / `l--` など）が常に勝つようになります。
- `lism-component` レイヤーは後方互換のため宣言に残しています（宣言から消すと、既存のユーザーCSS内の `@layer lism-component` が最後尾に再配置されて挙動が変わるため）。

### 独自クラスの命名規約を2分類へ統一 (#546)

- 独自クラスの分類を `b--`（Block Class）と `c--`（Custom Class）の2つに統一しました。
- `c--` の呼称を Component Class から Custom Class へ変更しました（`lism-custom` レイヤーに対応する自由なカスタムクラスで、粒度は問いません）。
- `p--` / `z--` の規約を廃止しました。

### その他

- 依存パッケージのセキュリティ更新を行いました。

### `@lism-css/ui` v.0.26.0 (2026.08.16)

**破壊的変更**を含むリリースです。`lism-css` v0.26.0 以上が必要です。

**`b--` クラスと `lism-block` レイヤーへの移行 (#559)**

- 全コンポーネントのクラスを `c--{name}` から `b--{name}` へ変更し、CSSの配置レイヤーを `@layer lism-component` から `@layer lism-block` へ移しました。要素（`_element`）とモディファイア（`--modifier`）の記法は変わりません。
- 移行方法: CSSやマークアップ内の `.c--{name}` を `.b--{name}` へ置換してください。コンポーネントを上書きしているCSSは `@layer lism-block` へ移すか、`b--` より強く上書きしたい場合は `@layer lism-custom` に置いてください。

**ベーススタイルをCSSへ移行 (#559)**

- これまで Lism Props（Property Class）として出力していたベーススタイルの一部をCSSへ移し、利用者側のCSSから上書きできるようにしました。あわせて次の既定値が変わっています。
- Badge: 既定の角丸をピル型（`--bdrs--99`）へ変更しました。
- Tabs: `variant="line"` を標準スタイルへ昇格し、`variant` の初期値を `'default'` にしました。既定の装飾は `.b--tabs--default` へ隔離しています。
- Avatar: 既定サイズを `--w: 2em` としてCSS側で管理するようにしました。
- Button / Accordion.Root / Details / NavMenu: 既定で出力していた `l--flex` / `l--stack` を廃止しました。レイアウトが必要な場合は `layout="flex"` などを指定してください。
- Details: Content の `flow="s"` を廃止し、子要素の間隔の既定が `--flow--base` になりました。従来の間隔を維持する場合は `.b--details_content { --flow--base: var(--flow--s) }` を指定してください。

**Tabs / Modal のアクセシビリティ改善 (#559, #563)**

- Tabs: roving tabindex と矢印 / Home / End キーによる操作に対応しました。パネルの `aria-hidden` を `hidden` 属性へ移行し、タブに `type="button"` と `id` を付与してパネルから `aria-labelledby` で参照するようにしました。React版でも `?lism-tab=` のディープリンクが使えます。
- Tabs: `defaultIndex` が範囲外のときに操作不能になる問題を修正しました。
- Modal: `Modal.OpenBtn` / `Modal.CloseBtn` に `type="button"` を、`Modal.OpenBtn` に `aria-haspopup="dialog"` を既定で付与するようにしました（props で上書きできます）。
- Modal: `prefers-reduced-motion: reduce` のとき、開閉アニメーションを無効化するようにしました。
- Modal: モーダル内でドラッグを開始して余白で離したときに、意図せず閉じてしまう問題を修正しました。
- Modal: `<form method="dialog">` の送信など `closeDialog()` を経由しないクローズでも、`data-is-open` の削除と `scrollbar-gutter` の復元が行われるようにしました。
- Modal: `setEvent` の非 `dialog` 要素サポートを廃止しました（フォーカストラップや背景の inert 化をネイティブ `dialog` に依存しているため）。

**Chatコンポーネントの削除 (#564)**

- Chat をパッケージから削除しました。マークアップの変更は不要です。ドキュメントの作例ページに掲載しているCSSを `@layer lism-block` ごとプロジェクトへコピーすれば、同じ見た目を再現できます。

## lism-css v.0.25.0 (2026.08.06)

- `--L` / `--C` / `--fz-mol` / `--hl-unit` / `--s-unit` をトークンの新グループ `vars` へ移動し、`lism.config` の `tokens` から上書きできるようにしました。

## lism-css v.0.21.0 (2026.05.26)

**破壊的変更**を含むリリースです。

### set クラスの命名変更 (#404)

- `set--var:xxx` 形式を `set--xxx` 形式へ戻しました（`set--var:hov` → `set--hov`、`set--var:bxsh` → `set--bxsh`、`set--var:bdrsInner` → `set--bdrsInner`、`set--var:s` → `set--s`）
- `set` prop の値も同様に `set="var:hov"` → `set="hov"` のように変更
- ベータ版のため後方互換 alias は提供していません

### contentSize Prop と set--bleed の追加 (#405)

- `contentSize` を Lism Prop として追加（プリセット値 `s` / `m` / `l` / `xl` はクラス、任意値は CSS 変数として出力）
- `set--bleed` をコア CSS に追加し、片側ブリードレイアウト用の `--bleed` 変数生成を提供
- `Wrapper` コンポーネントを `isWrapper` + `contentSize` の組み合わせに整理

### その他

- `isWrapper="xl"` プリセットに対応
- `pos`・`order` プロパティにブレークポイント対応（`bp: 1`）を追加
- `InlineAllowedTag` に `label` タグを追加

### `@lism-css/ui` v.0.21.0 (2026.05.26)

- lism-css 本体の set クラス命名整理（`set--var:xxx` → `set--xxx`）に追従

## lism-css v.0.20.0 (2026.05.20)

**破壊的変更**を含むリリースです。

### 方向系 Property Class の命名整理 (#378)

- inline-start / block-start などの方向プロパティを短く読みやすい新命名に統一（v0 のため後方互換 alias なし）
- padding / margin: `px-s/px-e/py-s/py-e` → `ps/pe/pbs/pbe`、`mx-s/mx-e/my-s/my-e` → `ms/me/mbs/mbe`
- border: `bd-x-s/bd-x-e/bd-y-s/bd-y-e` → `bd-s/bd-e/bd-bs/bd-be`
- inset: `i-x-s/i-x-e/i-y-s/i-y-e` → `i-s/i-e/i-bs/i-be`
- CSS変数 `--list-px-s` → `--list-ps`

### ブレークポイント対応プロパティの整理 (#394)

- main.css のサイズ削減のため、bp デフォルトサポートを見直し
- bp サポート廃止: `pl/pr/pt/pb`, `ml/mr/mt/mb`, `hl`, `lts`, `cg`, `rg`, `bg`
- bp サポートを `lg` まで拡張: `d`, `cols`, `g`, `gta/gtc/gtr`, `ga/gc/gr`
- bp:0 のプロパティに BP 指定した際、開発時に警告を表示

### hover 色のデフォルト変更 (#381)

- `-hov:-bgc` のデフォルト色を `var(--base-2)` から neutral mix（`color-mix`）に変更し、ライト/ダーク両方の背景で使えるように
- `--neutral` トークンを追加し、`-hov:neutral` クラスを廃止
- `--hov-bgc--default` でプロジェクト側のデフォルト差し替えに対応

### その他

- `--flow` デフォルト値の定義位置を root へ移動し、`lang="ja"` で少し広めに設定
- base スタイルの微調整

### `@lism-css/ui` v.0.20.0 (2026.05.20)

- Modal にデフォルトの背景ブラー（`backdrop-filter`）を追加（`--modal-blur` で変更可能）
- Callout / Alert からデフォルトの box-shadow を除去し、よりフラットな見た目に調整
- Callout のアイコン・タイトル周りのマークアップを整理（Icon サイズを `1.25em` に固定）
- lism-css 本体の方向系 Property Class 命名整理に追従（`bd-x-s` → `bd-s`、`px-s` → `ps`）

## How to use

`@lism-css/ui` パッケージで`Badge`(`b--badge`)として提供しています。


### Import
<ImportPackage component="Badge" packageName="@lism-css/ui" css="style.css" />


### Props

| プロパティ | 説明 |
|---|---|
|`variant`| `b--badge--{variant}` クラスを出力します。`outline`を用意しています。|

### スタイルの調整例

      <Badge fz="m">Badge</Badge>
    </Cluster>
  </PreviewArea>
  <PreviewCode slot="tab" label="JSX">
    ```jsx 'fz="s"' 'fz="m"'
    <Cluster g="15" ai="center">
    ```

  </PreviewCode>
  <PreviewCode slot="tab" label="HTML">

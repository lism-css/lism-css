ブラウザ標準の [Popover API](https://developer.mozilla.org/ja/docs/Web/API/Popover_API)（`popover`属性と`popovertarget`属性）だけで動作するため、クライアントJavaScriptは一切必要ありません。

初期値の`type="auto"`では、以下の挙動がすべてブラウザ側で提供されます。

- トリガーのクリックによる開閉
- 外側のクリックや<kbd>Esc</kbd>キーで閉じる（light dismiss）
- 閉じたあと、トリガーへフォーカスを戻す
- トリガーの`aria-expanded`の切り替え

:::note
`<Popover.Root>`の中に`<Popover.Trigger>`と`<Popover.Popup>`を置くと、`popovertarget`と`id`が自動で紐付きます。`<Popover.Close>`も同様です。

- ポップオーバーは閉じている間、支援技術からも見えません。**重要な操作や情報をポップオーバーの中だけに置かないでください。**
- `<Popover.Trigger>`と`<Popover.Close>`は`button`要素である必要があります。`popovertarget`属性は`button`（および`input type="button"`など）でしか機能しません。
- `<Popover.Popup>`には`role`を指定していません。フォームなど、まとまった操作を含む場合は`role="dialog"`と`aria-label`を指定してください。
:::

## How to use

`@lism-css/ui` パッケージで`Popover`として提供しています。


### Import

<ImportPackage component="Popover" packageName="@lism-css/ui" css="style.css" />

`<Popover.Root>`, `<Popover.Trigger>`, `<Popover.Popup>`, `<Popover.Close>`が利用できます。


### Props

| プロパティ | 説明 |
|---|---|
|<PropBadge>`<Popover.Root>`</PropBadge><br/>`popoverId`|`<Popover.Trigger>` / `<Popover.Close>`の`popovertarget`と、`<Popover.Popup>`の`id`に使われるIDを指定します。未指定の場合は自動生成されたIDが使われます。|
|<PropBadge>`<Popover.Trigger>`</PropBadge><br/>`popoverId`|`popovertarget`の値として出力されます。`<Popover.Root>`の外で単体利用するときにだけ指定します。|
|<PropBadge>`<Popover.Popup>`</PropBadge><br/>`id`|`id`属性として出力されます。`<Popover.Root>`の外で単体利用するときにだけ指定します。|
|<PropBadge>`<Popover.Popup>`</PropBadge><br/>`side`|ポップアップを表示する向きを指定します。`data-side`属性として出力されます。指定できる値は`top` / `bottom` / `left` / `right` / `inline-start` / `inline-end`で、初期値は`bottom`です。|
|<PropBadge>`<Popover.Popup>`</PropBadge><br/>`align`|`side`と直交する方向の揃え位置を指定します。`data-align`属性として出力されます。指定できる値は`start` / `center` / `end`で、初期値は`center`です。|
|<PropBadge>`<Popover.Popup>`</PropBadge><br/>`offset`|トリガーとポップアップの間隔を指定します。インラインスタイルの`--popover-offset`として出力されます。|
|<PropBadge>`<Popover.Popup>`</PropBadge><br/>`type`|`popover`属性の値として出力されます。指定できる値は`auto` / `manual`で、初期値は`auto`です。`manual`にすると、外側のクリックや<kbd>Esc</kbd>キーによる自動クローズ（light dismiss）が無効になり、`<Popover.Close>`などの`popovertarget`を持つボタンでしか閉じられなくなります。|
|<PropBadge>`<Popover.Close>`</PropBadge><br/>`popoverId`|`popovertarget`の値として出力されます。`<Popover.Root>`の外で単体利用するときにだけ指定します。|
|<PropBadge>`<Popover.Close>`</PropBadge><br/>`icon`|子要素を渡さない場合に表示されるアイコンを指定します。（デフォルト: `x`）|
|<PropBadge>`<Popover.Close>`</PropBadge><br/>`srText`|アイコン表示時にスクリーンリーダー向けに出力されるテキストを指定します。デフォルトは`Close`のため、日本語サイトでは`srText="閉じる"`の指定を推奨します。|

:::warning
`<Popover.Root>`の配下では、`<Popover.Trigger>` / `<Popover.Popup>` / `<Popover.Close>`に個別のIDを指定しないでください。IDを明示したい場合は`<Popover.Root>`の`popoverId`だけを使います。

子要素側の`popoverId` / `id`は、`<Popover.Root>`を使わずにパーツを離れた場所へ配置する（自分ですべてのパーツに同じIDを渡す）ための手段です。`<Popover.Root>`の配下で一部の子にだけ指定すると、紐付けが壊れてしまいます。
:::


### CSS変数

見た目の調整には、以下のCSS変数が使えます。

| 変数 | 初期値 | 説明 |
|---|---|---|
|`--popover-offset`|`var(--s5)`|トリガーとポップアップの間隔。|
|`--popover-duration`|`0.15s`|開閉時のフェードにかかる時間。`prefers-reduced-motion: reduce`の環境では`0s`になります。|

ポップアップの初期スタイルは、背景色`var(--base)`・余白`var(--s15)`に角丸と影を付けたカードです。配色や余白は、Lismのプロパティ（`bgc`, `c`, `p`, `bdrs`, `bxsh`など）で上書きしてください。

## ブラウザ対応

ポップオーバーの配置には [CSS Anchor Positioning](https://developer.mozilla.org/ja/docs/Web/CSS/CSS_anchor_positioning) を使用しています。

未対応のブラウザ（Firefox ESR 140 など）では、画面中央に表示されるカード（ブラウザ既定の配置）にフォールバックします。この場合、`side` / `align` / `offset` による位置調整は適用されません。

開閉・light dismiss・フォーカス制御は Popover API の機能なので、フォールバック時もそのまま動作します。

### ポリフィルを使う

[OddBird の CSS Anchor Positioning ポリフィル](https://github.com/oddbird/css-anchor-positioning)を読み込み、`<html>`に`data-anchor-polyfill`属性を付けると、中央配置のフォールバックが無効になり、アンカー配置のルールをポリフィルが処理するようになります。

```html
<html data-anchor-polyfill>
  <head>
    <script type="module">
      if (!('anchorName' in document.documentElement.style)) {
        import('https://unpkg.com/@oddbird/css-anchor-positioning');
      }
    </script>
  </head>
</html>
```

npmからインストールして、任意のタイミングで実行することもできます。

```bash
npm install @oddbird/css-anchor-positioning
```

```js
import polyfill from '@oddbird/css-anchor-positioning/fn';

polyfill(); // ポリフィルの適用完了時に解決される Promise を返します
```

:::warning
このポリフィルは、実行後に動的に追加された要素には適用されません。React などで後からマウントされるポップオーバーには効かない点にご注意ください。
:::

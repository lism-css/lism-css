クリックでコンテンツを開閉できるアコーディオンUIをdetails/summary要素で作成できるUIコンポーネントです。

[`Accordion`](/docs/ui/Accordion/)とは違い、jsを使わずCSSだけでの実装となっています。

`<Details.Summary>` の中身は、`<Details.Title>` と `<Details.Icon>` で構成します。

## How to use

`@lism-css/ui` パッケージで`Details`(`b--details`)として提供しています。


### Import

<ImportPackage component="Details" packageName="@lism-css/ui" css="style.css" />


以下のコンポーネントが利用できます。

- `<Details.Root>`: ルート要素（`details`要素）
- `<Details.Summary>`: 開閉のトリガー（`summary`要素）
- `<Details.Title>`: summary内のタイトル（デフォルトは `span`）
- `<Details.Icon>`: 開閉状態を示すアイコン（CSSで描画）
- `<Details.Content>`: 開閉されるコンテンツ


### Props


| プロパティ | 説明 | 
|---|---|
| <PropBadge>`<Details.Root>`</PropBadge><br/>`open` | 初期状態で展開します（`details`要素の`open`属性） |
| <PropBadge>`<Details.Root>`</PropBadge><br/>`--duration` | 展開アニメーションの秒数 |
| <PropBadge>`<Details.Title>`</PropBadge><br/>`as` | summary要素内のタイトルを出力するHTMLタグの種類。見出しタグなどを指定すると `set--plain` が付与されます |

### タイトルのHTMLタグを変更する

`<Details.Title>`はデフォルトではspanタグで出力されますが、`as`に`h3`などの見出しタグを指定することで、実際の見出し要素として出力できます。
見出しタグを指定した場合は、`set--plain`が付与されてデフォルトの見出しスタイルがリセットされます。

<Preview>
  <PreviewTitle>例</PreviewTitle>
  <PreviewArea p="20">
    <Details.Root bd>
      <Details.Summary>
        <Details.Title as="h3">Details Title</Details.Title>
        <Details.Icon />
      </Details.Summary>
      <Details.Content>
        <DummyText length="l" />
      </Details.Content>
    </Details.Root>
  </PreviewArea>
  <PreviewCode slot="tab" label="JSX">
    ```jsx 'as="h3"'
    <Details.Root bd>
      <Details.Summary>
        <Details.Title as="h3">Details Title</Details.Title>
        <Details.Icon />
      </Details.Summary>
      ...
    </Details.Root>
    ```
  </PreviewCode>
  <PreviewCode slot="tab" label="HTML">
  ```html "h3"
  <details class="b--details -bd">
    <summary class="b--details_summary">
      <h3 class="b--details_title set--plain">Details Title</h3>
      <span class="b--details_icon a--icon" aria-hidden="true"></span>
    </summary>
    ...
  </details>
  ```
  </PreviewCode>
</Preview>

### 複数同時展開を制限する

details/summaryの基本的な機能として、`name`属性を指定すると、同じ`name`のグループ内で同時に展開できる要素が一つのみになります。

### アニメーション時間を変更する

`<Details>`の開閉アニメーションの時間は`--duration`変数で管理しており、初期値は、`<Accordion>`と同じ`--acc-duration`になっています。

局所的な調整には `--duration`変数を調整し、全体的な調整には`:root`で`--acc-duration`を上書きしてください。

<Preview>
  <PreviewTitle>Preview</PreviewTitle>
  <PreviewArea p="20">
    <Details.Root bd style={{ '--duration': '.4s' }}>
      <Details.Summary>
        <Details.Title>Details Title</Details.Title>
        <Details.Icon />
      </Details.Summary>
      <Details.Content>
        <DummyText length="l" />
      </Details.Content>
    </Details.Root>
  </PreviewArea>
  <PreviewCode slot="tab" label="JSX">
```jsx "--duration"
<Details.Root bd style={{ '--duration': '.4s' }}>
  <Details.Summary>...</Details.Summary>
  <Details.Content>...</Details.Content>
</Details.Root>
```
  </PreviewCode>
  <PreviewCode slot="tab" label="HTML">
```html "--duration"
<details class="b--details -bd" style="--duration: 0.4s">...</details>
```
  </PreviewCode>
</Preview>

Lism CSS manages `line-height` through **half-leading values**, which is a somewhat unconventional approach.

Half-leading is the space above and below a line of text — the gap between the `line-height` value and the actual character height.


## How It Works

In Lism, the following style is applied to all elements:

```css
* {
  line-height: var(--lh, calc(1em + var(--hl) * 2));
}
```

This ties `line-height` to the `--hl` variable (the half-leading amount) by default, so **the spacing between text stays consistent regardless of font size**.

When `--lh` (a unitless ratio) is set, it takes precedence (this is what the `lh` property described below uses).

:::note
Because `line-height` is managed by this universal rule, setting `line-height` directly in plain CSS does not cascade to child elements (each child is recalculated by the `*` rule as well). Always control line spacing through the `--hl` / `--lh` variables (the `hl` / `lh` properties).
:::

## `lh` (line-height)

Line spacing is normally specified with the `hl` (half-leading) property (`-hl:*` classes, or the `hl` prop on `<Lism>`-based components). For cases where you want to manage the actual `line-height` as a unitless ratio, the independent `lh` property is available.

|Value|Behavior|
|---|---|
|`lh="xs"` / `"s"` / `"m"` / `"l"` / `"xl"`|Sets an [LH token](/en/docs/tokens/typography/#lh-line-height) (`1.25`–`2.25`) on `--lh`|
|`lh="1"`|`--lh: 1` (no extra line spacing)|
|Arbitrary numbers like `lh="1.7"`|Sets `--lh: 1.7`|

All of these are output through the `--lh` variable, so the unitless ratio is inherited by child elements and the line spacing is recalculated against each element's font size.

### `hl` vs `lh`

- `hl`: Manages line spacing as a fixed amount independent of font size. Use this by default.
- `lh`: Manages line spacing as a ratio of the font size. Use it for graphical typography where the font size changes significantly across screen sizes (e.g. hero headings) and you want the spacing to scale proportionally.

Note that inside an `lh` scope, descendants inherit `--lh`, which takes precedence — so `hl` (`--hl`) has no effect there.


## Why Use Half-Leading?

With a typical `line-height` like `1.6`, the effective line spacing grows as the font size increases.

That's fine for body text, but for headings the spacing becomes too large.

By fixing the half-leading to a constant value, the distance between lines stays the same regardless of font size.

A component for creating tab elements.
Only interaction behavior is provided — visual styling is intentionally left for you to customize.

Only `<Tabs.Tab>` and `<Tabs.Panel>` are recognized as children of `<Tabs.Item>`. Both must always be used together.
:::

## Usage

Provided as `Tabs` from the `@lism-css/ui` package.


### Import

<ImportPackage component="Tabs" script="tabs.js" packageName="@lism-css/ui" />


### Props

| Prop | Description |
|---|---|
|<PropBadge>`<Tabs.Root>`</PropBadge><br/>`variant`| Outputs the `b--tabs--{variant}` class. |
|<PropBadge>`<Tabs.Root>`</PropBadge><br/>`tabId`| A string ID used as the value for `aria-controls` to identify each tab. |
|<PropBadge>`<Tabs.Root>`</PropBadge><br/>`defaultIndex`| Specifies which tab to open initially. |
|<PropBadge>`<Tabs.Root>`</PropBadge><br/>`listProps`| Props passed to the list element (`b--tabs_list`) wrapping the tab buttons. |

{/* |<PropBadge>`<Tabs.Item>`</PropBadge><br/>`label` | Specifies the tab label text. | */}

{/* |<PropBadge>`<Tabs.Root>`</PropBadge><br/>`keepHeight`| Outputs `[data-tabs-height="keep"]`, fixing the overall height of the tabs to the tallest content panel. | */}


## Examples

### Default open tab

Use `defaultIndex` on `<Tabs.Root>` to specify which tab is open by default.
(Index numbers start from `1`.)

### Side-by-side tab layout

Setting `grid-template: 'list panel' auto / auto 1fr;` on `<Tabs.Root>` (`b--tabs`) places the tab list and content side by side.

At the same time, changing the tab list (`b--tabs_list`) buttons to stack vertically (`flex-direction: column;`) achieves the following layout.

<Preview>
  <PreviewTitle>Example: side-by-side layout on `@sm` and above</PreviewTitle>
  <PreviewArea p="30" resize>
    <Tabs.Root gt={[null, '"list panel" auto / auto 1fr']} listProps={{ fxd: [null, 'column'] }}>
      <Tabs.Item>
        <Tabs.Tab>
          <Fragment>Tab 1</Fragment>
        </Tabs.Tab>
        <Tabs.Panel>
          <DummyText pre="Tab 01: " />
        </Tabs.Panel>
      </Tabs.Item>

## Usage

Provided as `Badge` (`b--badge`) from the `@lism-css/ui` package.


### Import
<ImportPackage component="Badge" packageName="@lism-css/ui" css="style.css" />


### Props

| Prop | Description |
|---|---|
|`variant`<small>(optional)</small>| Outputs the `b--badge--{variant}` class. An `outline` style is provided by default. |

### Adjusting styles

Since the padding is defined in em units, changing the font size with `fz` scales the whole badge accordingly. The border radius can be adjusted with `bdrs`.

<Preview>
  <PreviewTitle>Adjusting size</PreviewTitle>
  <PreviewArea p="20" bg=":stripe">
    <Cluster g="15" ai="center">
      <Badge>Badge</Badge>
      <Badge fz="s">Badge</Badge>
      <Badge fz="m">Badge</Badge>
    </Cluster>
  </PreviewArea>
  <PreviewCode slot="tab" label="JSX">
    ```jsx 'fz="s"' 'fz="m"'
    <Cluster g="15" ai="center">
      <Badge>Badge</Badge>
      <Badge fz="s">Badge</Badge>
      <Badge fz="m">Badge</Badge>
    </Cluster>
    ```
  </PreviewCode>
  <PreviewCode slot="tab" label="HTML">
    ```html '-fz:s' '-fz:m'
    <div class="l--cluster -g:15 -ai:center">
      <span class="b--badge">Badge</span>
      <span class="b--badge -fz:s">Badge</span>
      <span class="b--badge -fz:m">Badge</span>
    </div>
    ```
  </PreviewCode>
</Preview>

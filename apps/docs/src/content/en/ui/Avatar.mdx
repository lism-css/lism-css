## Usage

Provided as `Avatar` (`b--avatar`) from the `@lism-css/ui` package.

### Import

<ImportPackage component="Avatar" packageName="@lism-css/ui" css="style.css" />


### Props

| Prop | Description |
|---|---|
|`size`| Specifies the size of the avatar. Default: `"2em"` |
|`src`| Path to the avatar image. |
|`alt`| Alt text for the image. |

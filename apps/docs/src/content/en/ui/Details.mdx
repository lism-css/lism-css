A UI component for creating collapsible accordion-style content using the `details`/`summary` elements.

Unlike [`Accordion`](/en/docs/ui/Accordion/), this component is implemented with CSS only — no JavaScript required.

## Usage

Provided as `Details` (`b--details`) from the `@lism-css/ui` package.


### Import

<ImportPackage component="Details" packageName="@lism-css/ui" css="style.css" />


The following components are available:

- `<Details.Root>`: The root element (`details` element)
- `<Details.Summary>`: The open/close trigger (`summary` element)
- `<Details.Title>`: The title inside the summary (defaults to `span`)
- `<Details.Icon>`: An icon indicating the open/close state (rendered with CSS)
- `<Details.Content>`: The collapsible content


### Props


| Prop | Description |
|---|---|
| <PropBadge>`<Details.Root>`</PropBadge><br/>`open` | Expands the details initially (the `open` attribute of the `details` element). |
| <PropBadge>`<Details.Root>`</PropBadge><br/>`--duration` | Duration of the expand/collapse animation. |
| <PropBadge>`<Details.Title>`</PropBadge><br/>`as` | The HTML tag used to render the title inside the summary element. When a heading tag is specified, `set--plain` is applied. |

### Changing the title tag

`<Details.Title>` renders as a `span` by default, but you can specify a heading tag such as `h3` via `as` to render it as an actual heading element.
When a heading tag is specified, `set--plain` is applied to reset the default heading styles.

<Preview>
  <PreviewTitle>Example</PreviewTitle>
  <PreviewArea p="20">
    <Details.Root bd>
      <Details.Summary>
        <Details.Title as="h3">Details Title</Details.Title>
        <Details.Icon />
      </Details.Summary>
      <Details.Content>
        <DummyText length="l" />
      </Details.Content>
    </Details.Root>
  </PreviewArea>
  <PreviewCode slot="tab" label="JSX">
    ```jsx 'as="h3"'
    <Details.Root bd>
      <Details.Summary>
        <Details.Title as="h3">Details Title</Details.Title>
        <Details.Icon />
      </Details.Summary>
      ...
    </Details.Root>
    ```
  </PreviewCode>
  <PreviewCode slot="tab" label="HTML">
  ```html "h3"
  <details class="b--details -bd">
    <summary class="b--details_summary">
      <h3 class="b--details_title set--plain">Details Title</h3>
      <span class="b--details_icon a--icon" aria-hidden="true"></span>
    </summary>
    ...
  </details>
  ```
  </PreviewCode>
</Preview>

:::warning
::title[Heading elements inside summary]
There was a known issue where screen readers could not detect the role of heading elements placed inside `summary`, but as of 2026, this has been largely resolved in modern browsers.
:::

### Changing the animation duration

The duration of the `<Details>` open/close animation is controlled by the `--duration` variable, which defaults to the same value as `<Accordion>` — `--acc-duration`.

For local adjustments, override the `--duration` variable. For global adjustments, override `--acc-duration` on `:root`.

<Preview>
  <PreviewTitle>Preview</PreviewTitle>
  <PreviewArea p="20">

        <Details.Title>Details Title</Details.Title>
        <Details.Icon />
      </Details.Summary>

        <DummyText length="l" />

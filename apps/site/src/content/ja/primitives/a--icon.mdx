`a--icon`は、アイコン要素を表示するためのクラスです。

<SrcCode path="src/scss/primitives/atomic/_icon.scss" />


## Lismコンポーネント

`<Icon>`は、`label`が指定されていれば`aria-label`と`role="img"`を、指定がなければ`aria-hidden="true"`を自動的に付与します。

### Import

<ImportPackage component="Icon" />

### 出力されるHTML構造

実際に出力されるタグは`icon`・`viewBox`・`src`・`as`の指定方法によって`svg`や`img`などに変わりますが、`aria-hidden`/`aria-label`の付与規則はどのタグでも共通です。

```pug
svg.a--icon[aria-hidden="true"]

or

svg.a--icon[aria-label="..."][role="img"]
```

### 専用Props

| プロパティ | 説明 |
|---|---|
| `icon` | アイコンコンポーネント・SVG文字列・`{as, ...exProps}`形式のオブジェクトを指定します。 |
| `size` | SVGの幅・高さの既定値。明示した`width`・`height`を優先します。 |
| `label` | `aria-label`として出力します。指定があれば`role="img"`が同時に出力され、指定がない場合は`aria-hidden="true"`が出力されます。 |


## Usage


### `@lism-css/icons`を利用する方法

`@lism-css/icons`は、Lism CSSと同じ開発元が提供する、React・Astro向けのSVGアイコン集です。`lism-css`本体にはアイコンのSVGデータを含まないため、別途インストールして必要なコンポーネントを`icon`に渡します。

インストール方法と[収録アイコン一覧](/docs/packages/icons/#収録アイコン一覧)は、[`@lism-css/icons`の解説ページ](/docs/packages/icons/)をご覧ください。

Reactでは`@lism-css/icons/react`、Astroでは`@lism-css/icons/astro`からimportします。

### `as`・`exProps`で指定する方法

`icon={HomeIcon}`の代わりに、Lismコンポーネントの共通プロパティ`as`でも指定できます。

<Preview>
  <PreviewTitle>アイコンコンポーネントを`as`に指定する</PreviewTitle>
  <PreviewArea p="20">
    <Icon as={HomeIcon} size="2em" />
  </PreviewArea>
  <PreviewCode>
```jsx "as={HomeIcon}"
import { HomeIcon } from '@lism-css/icons/react';
import { Icon } from 'lism-css/react';

<Icon as={HomeIcon} size="2em" />
```
  </PreviewCode>
</Preview>


`exProps`には、読み込んだアイコンコンポーネントへ渡すプロパティをまとめて指定できます。次の例では、線幅とサイズを指定しています。

<Preview>
  <PreviewTitle>`HomeIcon`用のプロパティを指定する</PreviewTitle>
  <PreviewArea p="20">
    <Icon as={HomeIcon} exProps={{ strokeWidth: 2, size: '3em' }} c="blue" />
  </PreviewArea>
  <PreviewCode>
    ```jsx "as=" "exProps="
    <Icon as={HomeIcon} exProps={{ strokeWidth: 2, size: '3em' }} c="blue" />
    ```
  </PreviewCode>
</Preview>

#### `as`・`exProps`を`icon`にまとめて指定する方法

:::info
`<Icon>`では、以下のような形式で`as`, `exProps`を一括指定することもできます。

```jsx
<Icon icon={{as:Component, exProps1, exProps2, ...}} />
```
:::


<Preview>
  <PreviewTitle>`icon`に`as`, `exProps`を一括指定する例</PreviewTitle>
  <PreviewArea p="20">
    <Icon icon={{ as: HomeIcon, strokeWidth: 2, size: '3em' }} c="blue" />
  </PreviewArea>
    <PreviewCode slot="tab" label="一括">
    ```jsx "strokeWidth:2, size:'3em'" "as:HomeIcon"
    <Icon icon={{as:HomeIcon, strokeWidth:2, size:'3em'}} c="blue" />
    ```
  </PreviewCode>
  <PreviewCode slot="tab" label="分割">
    ```jsx "as=" "exProps="
    <Icon as={HomeIcon} exProps={{strokeWidth:2, size:'3em'}} c="blue" />
    ```
  </PreviewCode>

</Preview>

`react-icons`や`@phosphor-icons/react`などのサードパーティ製アイコンも、同じように`icon`や`as`で指定できます。AstroでReact製のアイコンを使う場合は、Astro側でReactインテグレーションを有効にしてください。


### SVG文字列を渡す方法

`icon`には`<svg`で始まるSVG全体の文字列も渡せます。`viewBox`・線幅などのSVG属性を含めて指定します。

```jsx
<Icon icon={'<svg viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="1.5"><path d="m5 12 4 4L19 6" /></svg>'} c="green" />
```

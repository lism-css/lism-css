# パターンの共通ダミーテキスト

`apps/docs`のパターンで使う日本語のダミー文言を、カテゴリごとにまとめる。見出し・説明文・リンク文言を揃え、レイアウトの違いを比べやすくする。

## Feature

SaaSソフトウェア系とデザインスタジオ系の2テーマを用意する。Feature01/02の日英プレビューで使用する。

### 使い方

- SaaSソフトウェア系は4項目を用意し、3項目のレイアウトでは先頭3つを使う。デザインスタジオ系は3項目で構成する。
- リンク文言は両テーマとも「詳しく見る」に統一する。
- Feature01はSaaS系、Feature02はデザインスタジオ系を使う。

### SaaSソフトウェア系

作成中のダミープロダクト画面に合わせ、プロジェクト管理サービス「DevFlow」を題材にする。

**メイン見出し**

やることが見える。  
チームが動く。

英語版は次のコピーを維持する。

Your team’s work,  
all in one place.

日本語の新しいメイン見出しはプレビュー未反映。

**導入文**

タスクも、進捗も、チームの情報も。DevFlowが毎日のプロジェクト管理をすっきりまとめます。

| 特徴の見出し | 説明文 |
| --- | --- |
| タスクをまとめて管理 | 担当者や期限を決めて、やることを整理。ボードや一覧で、次に取り組む仕事を確認できます。 |
| プロジェクトの進捗を把握 | 完了したタスクや残りの作業をひと目で確認。チームの状況を見ながら、計画を調整できます。 |
| チームの情報を共有 | ドキュメントや日々の更新をひとつの場所に。必要な情報を共有し、認識のずれを減らします。 |
| 予定をひと目で確認 | タスクの期限やスプリントの予定をカレンダーに集約。先の予定を見渡して、無理なく仕事を進められます。 |

### デザインスタジオ系

ブランディング・Web制作・公開後の運用支援を扱う架空のWebデザインスタジオを題材にする。

**メイン見出し**

らしさを見つけて、伝わるかたちに。

**導入文**

ブランドの考え方から、Webサイトの制作・運用まで。対話を重ねながら、一貫したデザインで事業を支えます。

| 特徴の見出し | 説明文 |
| --- | --- |
| ブランドをかたちにする | 大切にしている想いや事業の強みを整理。言葉やロゴ、色を通して、そのブランドらしさをかたちにします。 |
| Webで魅力を伝える | 届けたい相手と伝えたい内容を整理。情報の構成から見た目まで、目的に合ったWebサイトをつくります。 |
| 公開後の成長を支える | 公開後の反応を確かめ、課題を整理。日々の更新から内容やデザインの見直しまで、継続して支えます。 |

英語版の見出しは、順に「Branding」「Web Design」「Maintenance」を使う。

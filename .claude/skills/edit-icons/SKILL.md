# Edit Icons

指定アイコンの編集に必要な情報だけ取得し、原寸・コピー・作図の整合性を保つ。アプリにアイコンを配置する作業には使わない。

## 対象を絞る

- 作業するworktreeを確認する。実行コマンドの基準はそのルートとし、別worktreeの同名.aiを操作しない。
- 最初は指定アイコン名だけ調べる。派生・塗り版への影響を確認し、同じ部品を持つという理由だけで別アイコンまで変更しない。
- [設計文書](../../../packages/icons/design/original/design.md)は、関連する個別仕様と今回使う共通ルールの節を読む。全図形の座標・全アイコン・文書全文を毎回出力しない。

読み取り専用ヘルパーで、原寸・一覧・作図の所在、外寸、線幅、頂点数、説明とコピーの形状一致を取得する。

```bash
python3 .claude/skills/edit-icons/scripts/inspect_icons.py {icon} [追加のicon]
```

座標が必要なら、役割を指定して追加取得する。`--points`だけの場合は原寸に限定する。

```bash
python3 .claude/skills/edit-icons/scripts/inspect_icons.py {icon} --role master --points
```

ヘルパーの読み取り結果は現在のIllustrator上の状態。コピーの不一致・欠落は報告であり、自動修正や保存は行わない。未収録のアイコンを追加するときは、作図が近い既存アイコンを参照し、作図セットの生成と兄弟からのガイド複製は[制作操作](references/editing.md#制作操作)のスクリプトで行う。

## 編集・反映

Illustrator操作前に[自動化の注意点](../../../documents/illustrator-automation.md)を読む。対象グループの対応とコピーの扱いは[編集時の参照](references/editing.md)を必要な箇所だけ読む。

共通ガイドの配置・作図説明の並べ直しには、[制作操作](references/editing.md#制作操作)のスクリプトを使う。ガイドのシンボル定義を共有し、配置座標や一覧の並びを毎回JSXへ書き直さない。

1. 原寸と今回変更するコピー・ガイドを特定し、現在の寸法とユーザーが求める寸法を区別する。中心線・regularの外縁・基準枠のどれを揃えるか決める。
2. 変更前の状態を復元可能にする。未保存のユーザー編集はディスク上のコピーだけでは保護できない。別名保存する場合は、作業対象の完全パスも追跡する。
3. 原寸を編集し、同じアイコンのlight・bold・作図用コピーへ反映する。線幅・色・不透明度・配置は役割ごとに維持する。塗り版と寸法ガイドは形状の意味に合わせて更新する。
4. 指定アイコンを再取得し、意図した寸法、コピーとの形状一致、線幅、変更した円弧の接続や塗りの穴を検証する。対象外への影響確認は変更手段に応じて絞る。
5. 寸法・構成の変更を作図説明と設計文書へ反映し、設計用.aiを元のパスで保存する。結果は変更箇所・寸法・検証結果を短く伝える。

復元は対象アイコンとそのコピー・説明だけを戻す。同じ.aiにある他アイコンの調整を、ファイル全体の置換で巻き戻さない。

中断・タイムアウト後は、実行ログ・開いている文書の完全パス・保存状態を確認してから再開する。処理が止まったと決めつけて同じ更新を重ねない。

## 書き出し・ビルド

形状を試している段階では設計用.aiまで。書き出しやパッケージへの反映が依頼されたら、[制作スクリプトの手順](../../../packages/icons/scripts/README.md#設計からパッケージへ同期する)を最後まで実行する。そこに記載されたルートのビルドはコアへの組み込み更新も含む。

確認コマンドは同文書を参照し、生成物の一致と必要な描画検証を行う。ビルド済みというだけで、コアにも反映されたと判断しない。

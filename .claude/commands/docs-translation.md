# Translation Sync

`apps/docs/src/content/ja/` の MDX ドキュメントを英語に翻訳し、`apps/docs/src/content/en/` に同期します。

日本語（`ja/`）を正として、英語（`en/`）を同期先とします。

翻訳の詳細ルール（翻訳する/しない対象・用語対応表・直訳回避パターン・セルフチェック）は、すべて `lism-docs-translator` サブエージェント（`.claude/agents/lism-docs-translator.md`）に集約されている。コマンド側からガイドラインを再掲する必要はない。


## 対象範囲

- `$ARGUMENTS` でファイルやディレクトリが指定されている場合はその範囲のみ対象とする
- `root` が指定された場合は `ja/` 直下の mdx ファイルのみ対象とする（サブディレクトリは除外）
- 未指定の場合は `ja/` 配下の全 `.mdx` ファイルを対象とする
- ただし `_demo/` 配下は常に除外する（`en/` から `../ja/_demo/` を直接 import して共用する）


## 作業手順

### 1. ファイル一覧の取得と分類

`ja/` と `en/` の MDX ファイル一覧を Glob で取得し、以下の3カテゴリに分類する：

| カテゴリ | 条件 | アクション |
| --- | --- | --- |
| **新規** | `ja/` にあるが `en/` にない | 翻訳して `en/` に作成 |
| **更新候補** | `ja/` と `en/` の両方にある | サブエージェントに渡し、差分があれば更新 |
| **孤立** | `en/` にあるが `ja/` にない | 削除対象として報告 |

更新候補の差分判定はコマンド側では行わない。メインエージェントが全ファイルを読むとコンテキストを圧迫するため、担当サブエージェントが `ja/` と `en/` を読み比べ、差分がなければ「スキップ」として報告する。
差分の概要を把握済みの場合（`docs-update` のフェーズ1直後など）は、その概要をサブエージェントに渡す。


### 2. 分類結果の報告

分類結果をユーザーに報告し、実行の承認を得る。

```
## 翻訳同期プラン

### 新規作成（{n}件）
- ja/path/to/file.mdx

### 更新候補（{n}件）
- ja/path/to/file.mdx

### 削除（{n}件）
- en/path/to/file.mdx（対応する ja/ ファイルなし）

実行してよろしいですか？
```


### 3. 翻訳の実行

承認後、以下を実行する：

#### 3a. 孤立ファイルの削除

`en/` にのみ存在するファイルを削除する。

#### 3b. 翻訳サブエージェントの起動

新規・更新候補のファイルを `.claude/commands/docs-update.md` の「対象ファイルの分類とグルーピング」表と同じグループに分け、`lism-docs-translator` サブエージェントを並列起動する。3件以下のグループは隣接グループと統合し、多いグループは分割してよい。

各サブエージェントに伝える情報：
- 担当ファイルパスの一覧（`ja/` 基準）
- 各ファイルが「新規作成」か「更新候補」か
- 差分の概要が分かっている場合はその内容


### 4. 検証（コマンド側で実施）

全サブエージェントの完了後、結果の報告の前に行う。

1. **日本語残留チェック**。リポジトリルートで実行する：

   ```bash
   rg -n '[一-龥ぁ-んァ-ヶー々]' apps/docs/src/content/en --glob '*.mdx'
   ```

   フォント見本のように `ja/` 側でも同じ位置に同じ日本語を表示用に置いている箇所だけは例外。それ以外は担当サブエージェントに差し戻す。`<DummyText lang="ja"` の残留も同様に確認する。

2. **ビルド確認**。`runner` サブエージェントで `nr build:docs` を実行し、MDX が壊れていないことを確認する。`nr dev:docs` が起動中に build すると dev 側のコンテンツストアが壊れるため、起動中ならビルドを行わずその旨を報告する。失敗時はエラーの要点を報告し、修正は勝手に行わずユーザーの判断を仰ぐ。


### 5. 結果の報告

各サブエージェントの結果をまとめて報告する。

```
## 翻訳同期結果

### 新規作成（{n}件）
- en/path/to/file.mdx — {英語タイトル}

### 更新（{n}件）
- en/path/to/file.mdx — {変更概要}

### 削除（{n}件）
- en/path/to/file.mdx — 削除済み

### スキップ（{n}件）
- en/path/to/file.mdx — 差分なし

### 検証
- 日本語残留: なし / {n}件を差し戻して解消
- ビルド: 成功 / 失敗（要点） / 未実施（理由）
```

あわせて、サブエージェントがセルフチェックで検出・修正した問題の件数と、翻訳ガイドラインに該当しない判断を行った箇所があればその旨を伝える。
